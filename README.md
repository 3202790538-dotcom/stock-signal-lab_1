## 当前主要流程：长线个人计划（2026-11-11）

三个入口：**我的计划、股票研究、账户与设置**。

计划首页先显示当前策略摘要和账户重点，点击“调整策略”再编辑；“我的持仓／自选机会”分开查看，可按减持复核、条件买入、待核验、持有等待筛选。每行“查看规则”展开原因与计算，显示排序不改变后台分配数量。手工账户草稿在当前页面会话内切换工作区时保留，保存或撤销后可直接进入计划；从计划进入股票研究时有返回入口。

1. 在“账户与设置”继续使用 IBKR 手动快照，或填写美元现金和手工持仓（代码、股数、平均成本、可选估值价、计划止损、行业），保存后选择“手工账户”。两份账户独立保存，互不覆盖。
2. 在“我的计划”设置账户资金比例 0–100%、年度收益目标、最大回撤容忍及策略。默认长线趋势，另可选趋势回踩、月度动量轮动；允许盈利后加仓，禁止亏损补仓。
3. 保存后查看实际持仓行动与自选候选，展开每行核对条件、参考价、止损、共享现金及风险预算。没有完整资料的数量保留“待核验”；计划不会下单。
4. 成交后手动更新账户。每日行情会重估手工持仓，但不知道券商新发生的交易，不会自动改变现金、股数或成本。

默认长线趋势按 60 日突破、50/200 日均线方向与市场条件筛选；两次已完成收盘跌破 50 日均线触发退出复核。每笔风险不超过分配资金的 min(0.75%, 回撤容忍/40)，组合计划止损风险不超过 min(3%, 回撤容忍/10)，并检查单股 25%、半导体 60%、现金与总投入上限。不新增融资，也不把尚未成交的卖出款分配给买入。

每天北京时间 09:00 自动更新一次；本机服务需要运行，关闭电脑或休眠时无法执行，下次启动补做当前未执行周期。价格、财报、新闻分别显示结果；任何失败保留此前有效数据和成功时间。进入研究页仍可按缓存时效补充单只股票资料，手动“刷新行情”也保留。

收益目标仅用于目标金额与评估，不代表可达到，更不会自动放大仓位；回撤容忍用于限制预算，不保证实际损失上限。缺少账户历史高点时实际回撤为未知。新长线规则、完整自选池和盈利加仓尚无同口径独立回测，旧固定五股成绩不验证本计划。证券身份与行业从 SEC 当前代码、CIK、SIC 分类核验，基金类型另行识别；公开资料保存来源和核验时间，30 天失效，随行情更新重查。未手填行业时使用这些证据，明确填写的行业不覆盖。基金不被视为零半导体敞口；基金、壳公司、非美元等显示“策略不适用”，短历史显示实际日线数，缺少个人计划止损单列“待补充账户信息”。手工账户当前支持美元多头，手填止损不代表券商已有止损订单。

本机接口：`GET/PUT /api/personal-settings`、`GET/PUT /api/manual-account`、`POST /api/personal-plan`、`GET /api/daily-sync-status`。设置和手工数据位于私有 `backend/data/`，无下单接口。

## 数据

- 持仓：经用户授权由 IBKR 读取的本机快照。界面显示同步时间；刷新行情不会更新 IBKR 股数、成本、净值。
- IBKR 自选：2026-11-10 导入 Favorites（70项）与 AI（1项），按合约去重共70项；ORCL保留两个分组归属。68个股票/ETF已接入公开USD日线；USD.CNH外汇与TSEJ 6981村田制作所保留在清单并注明暂不支持报价。自选名单是手动导入快照，行情按每日周期更新，不会自动同步IBKR名单或账户。
- 自选支持分组、搜索、本地收藏和每页10/20/50项；单个标的获取失败不会拖住其他行情，有缓存时标明缓存日期，无缓存时保留失败原因。个股研究与单股回测可选导入的有行情标的；ETF不套用企业财报与EPS估值。
- 基本面：自动财报优先读取 SEC；SKHY 使用公司官方韩元财报。2026-11-01 摘要保留于“走势与研究存档”，与自动财报分开标注。
- Qlib：日线均线、阶段收益、历史波动率。RSI按Wilder公式计算。长窗口不足时返回空值。没有训练预测模型；波段规则回测由独立本地引擎执行。
- 个股研究：5/20/60/120/252日价格收益、长期均线排列、回撤、历史价位、量比、单日历史VaR/ES、趋势切换后续表现。相关性按每对股票共同收益日期对齐；集中度只覆盖七只关注股。估值计算器可填年度EPS；MU预填已公布FY2026 GAAP EPS，修改即变为手动假设。公司摘要是研究存档；仅已核实的事件显示具体时间。
- 账户风控：完整IBKR头寸、账户保证金指标、各币种已结算借款、手动年利率的简单利息估算、股价下跌与维持保证金金额上调情景。币种BASE是汇总，不重复计息。股票压力以逐项市值计算，汇率及其他资产保持不变；不预测实际强平线。账户总值和持仓为分次读取，差额在数据检查中保留。

`backend/data/` 包含私人持仓和行情缓存，已加入 `.gitignore`。前后台仅监听 127.0.0.1。

## 自动研究与回测

- 个股研究 → 自动财报与估值：最多八季度的营收、利润、经营现金流、资本开支和自由现金流；完整连续四季度才给TTM。现金流累计值按相同期间差额推导，重述口径不一致时留空。同行市值和倍数采用价格与有日期的SEC股数估算，保留披露链接；GOOG多股类、SKHY ADR缺少映射时不计算相关估值。
- 个股研究 → 新闻与公告：Yahoo Finance RSS新闻与SEC披露时间轴。过滤无公司提及的文章，摘要提及单独标注；指标标签为关键词规则，不代表因果判断。
- 财报缓存12小时、新闻缓存15分钟；进入研究页或重新聚焦窗口时检查过期数据，也可分别点击更新。失败保留上次有效缓存，不会更新IBKR账户。
- 波段回测 → 单股波段回测（保留的原实验）：默认收盘突破此前20日最高价，次日开盘买入，含入场日持有10个交易日，每侧手续费与滑点各5bps。支持调整参数、日期和模拟本金，展示净收益、回撤、逐笔胜率、平均盈亏比、利润因子及同窗买入持有基准。未完成交易按市值保留；未建模分红、拆股、税费或真实市场冲击。

财报模块独立使用 `.venv-research`，依赖列于 `backend/requirements-research.txt`。SEC联系邮箱位于本机私有的 `backend/data/research-settings.json`，仅用于请求标识，不通过页面API提供。目前使用公开数据源，无需FMP或模型API密钥。

## 可调目标的策略研究

“波段回测 → 目标策略研究”保留原先的目标年化收益和可接受历史回撤控件，默认 50% / 30%。目标变化后自动筛选突破回看、持有周期和初始资金分配比例；此原实验没有新增完整策略的止损及共享账户风控，目标不是未来收益预测，历史回撤目标也不是实盘止损保证。

筛选只用前段历史，选定后在后段历史验证，并与同窗等额买入持有比较。资金分配不使用融资，未投资部分不计利息。策略仍为本机研究和模拟，没有连接自动下单。IBKR 按用户选择继续手动同步；账户快照与自动行情分别显示时间。

## 历史研究：固定五股完整策略与操作说明

进入“股票研究 → 历史回测 → 完整策略”。默认趋势突破、进取档、年化研究目标 50%；另可选趋势回调、周频动量轮动，以及保守/均衡风险档。选择保存在本机，修改后自动重算。详细规则版本见 `docs/superpowers/specs/2026-11-10-complete-trading-rules-design.md`。

完整策略固定研究 NVDA、MRVL、AVGO、MU、GOOG，SPY 用于市场状态与基准；导入自选不改变这个股票池。单股波段回测则跟随当前选中的有行情标的，不使用实际IBKR持仓数量或买入成本。

- 标题旁“使用说明”解释使用步骤、术语、当前生效参数、股数公式、止损与暂停恢复。
- “操作明细”区分后段验证与全段模拟；按期末持仓、已平仓交易、风控事件、信号/跳过原因查看。展开头寸可核对条件观察值、数量约束、成交及费用、止损变化和退出原因。
- 新组合引擎使用共享现金、整股、ATR 止损、单股/行业/总仓位及初始风险限额。先处理开盘卖出/减仓，再买入，最后处理盘中止损；禁止把盘中卖出现金倒用于开盘买入。
- 风险预设的回撤目标为 10%/20%/30%；默认每笔初始止损预算 0.75%、单股 25%、半导体 60%。每日收盘回撤达到目标的 1/3 降风险、2/3 清仓暂停；恢复不能抹掉整段历史回撤。它们不是保证损失上限。
- 每模板 6 组固定候选，200 日指标预热后按 70%/30% 训练/验证。仅训练选参，单独比较 SPY、股票池等额持有和双倍成本。统一期末估值，不虚构清仓。全段模拟包含训练数据，不能当作独立验证。
- 行情刷新现在同时保存已下载的 SPY 历史。日期缺失/不齐会拒绝研究；同步失败、正在更新、研究行情缺字段或快照超过 24 小时未同步时，禁止发布新候选，历史结果标明日期。
- API：`GET /api/strategy-rules`；`POST /api/portfolio-study`，参数 `templateId`、`riskProfile`、`targetReturnPct`。只传入公共行情，不读取实际账户用于策略仓位，不存在下单路径。

本版仍是未处理拆股/分红的原始价格探索回测，当前固定五股池、约两年样本、日线成交近似有明显限制。2026-11-09 数据的默认完整突破策略，后段验证 90 日累计 -1.82%、折算年化 -5.02%、最大回撤 1.96%，仅 3 笔平仓；未达到年化 50% 目标。新规则不能套用旧实验的收益成绩。

## 旧持仓行动计划（接口保留，主界面已由我的计划替代）

旧版 `holdings-plan` 仅分析 IBKR 手动同步快照中的实际非零头寸，保留零碎股。可选择趋势突破、趋势回调或动量轮动，以及保守／均衡／进取档。允许盈利后顺势加仓、禁止亏损补仓；收盘价与券商价格都必须高于成本，账户融资、集中度及资金限额优先检查。行情缺少的实际持仓股票会加入公开报价范围，不改动券商自选分组。

展开任一股票，可查看持有、加仓、减仓、退出四种条件情景、逐项检查、指标与参考价。它们是互斥复核情景，减仓示例不能再与退出数量相加。现有真实止损、原始入场日期和连续净值未核实，因此不虚构加仓股数、原有移动止损、持有期退出或账户历史回撤；收盘减2ATR仅为新计划的讨论参考。动量轮动在完整候选池周排名未核验前不产生加仓候选。

账户按最早的分项读取时间、行情按生成时间分别检查24小时有效期，页面长时间打开也会自动停止显示过期候选。日线另需与SPY及最近完成工作日一致；尚未接入交易所节假日日历，假日或提前休市可能保守暂停并要求核实。刷新失败／进行中也暂停操作候选，旧数据保留日期供查看。刷新计划不重新读取券商；账户仍按用户选择手动同步。

本功能不预测未来最佳股票或日期，不执行交易，现有五股完整回测独立保留，不为新增持仓加仓规则背书。接口 `POST /api/holdings-plan` 接受 `templateId`、`riskProfile`、`allowProfitAdd`，仅进行本机只读计算。
